🔐 AUTENTICAÇÃO
O sistema NÃO usa Supabase Auth.

Fluxo de login:

1. Usuário insere Código de Acesso
2. Informa Data de Nascimento
3. Função validate_access_code() consulta o banco
4. Se válido → sessão no localStorage
5. Redirect ao Dashboard com perfil carregado

Blindagem:
• CPF e access_code com REVOKE no banco
• Front nunca envia dados sensíveis de volta
• RLS aberto (login customizado, sem auth.uid())
🛡️ SEGURANÇA
Row Level Security (RLS):

• Todas as 7 tabelas com RLS habilitado
• Policies: SELECT/INSERT/UPDATE/DELETE
• Acesso universal (login customizado)

Foreign Keys:

• Todas com ON DELETE SET NULL
• Nunca CASCADE — evita perda em cascata

Frontend:

• requireAuth() em cada página
• requireAdmin() para painel admin
• Sessão no localStorage
• Logout limpa toda sessão
